# Demo provider dashboards

These accounts are for local testing only. Each service has 15 approved providers, all using the same password:

```text
Password: Provider@123
```

| Service | Login email pattern |
| --- | --- |
| Plumbing | `plumbing.provider01@demo.local` to `plumbing.provider15@demo.local` |
| Electrical | `electrical.provider01@demo.local` to `electrical.provider15@demo.local` |
| Cleaning | `cleaning.provider01@demo.local` to `cleaning.provider15@demo.local` |
| Carpentry | `carpentry.provider01@demo.local` to `carpentry.provider15@demo.local` |
| Appliance Repair | `appliance-repair.provider01@demo.local` to `appliance-repair.provider15@demo.local` |
| Painting | `painting.provider01@demo.local` to `painting.provider15@demo.local` |

For example, sign in as `plumbing.provider01@demo.local` with `Provider@123`, then open **My dashboard**. The account is already approved and can accept or decline bookings.

Do not use these shared credentials in a public deployment.
