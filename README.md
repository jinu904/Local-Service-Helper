# Local Service Helper

The React application lives in `local-service-helper`.

## Open without installing anything

Open `local-service-helper/standalone/index.html` in a browser. The top-level `index.html` redirects there automatically.

## Develop with React

```powershell
cd .\local-service-helper
npm install
npm run dev
```

Open the local address printed by Vite, normally `http://localhost:5173`.
